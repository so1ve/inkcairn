# Inkcairn Demo

Inkcairn turns a directory of durable Markdown files into a compact static
blog. This is a notebook about programming languages, small tools, and the
details that make software easier to understand.

## Projects

- **Inkcairn** — a small generator for blogs that should remain ordinary files.
- **Borrowed Time** — notes on ownership, lifetimes, and resource-aware software
